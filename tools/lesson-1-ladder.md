# 推断阶梯复盘表（Ladder of Inference）

> 配套《第一课：你说的，和你做的，为什么不一样？》
> 用途：把一次"说的≠做的"冲突，按 6 级拆开，标出你跳跃到的那一级。

## 六级阶梯（从下往上）

| 级 | 名称 | 你在这一级做了什么（如实填写） |
|---|---|---|
| 6 | 采取行动 |   |
| 5 | 得出信念 |   |
| 4 | 形成假定 |   |
| 3 | 赋予意义 |   |
| 2 | 选择性观察 |   |
| 1 | 真实数据 |   |

## 复盘步骤
1. 选一次最近的人际冲突（比如会上意见被驳回、下属没执行）。
2. 从**第 6 级（你采取的行动）**开始，往回填：你当时基于什么信念行动？
3. 一直填到第 1 级：有哪些**客观事实**是大家都看到的？又有哪些是你**脑补**的？
4. 用箭头标出：你从第几级"跳"到了第 6 级，跳过了哪些中间步骤。

## 关键问题（下爬一级用）
- 我当时**选择性注意**了什么？又**忽略了**什么证据？
- 我的**假定**是什么？我验证过它吗？
- 如果当面说出"我的假定是……你是怎么看的？"，结果会有什么不同？

## 本周练习
在下次冲突里，主动说出你的一个隐含假定，并问对方"你是怎么看的？"，记录对方的反应与你的收获。

（来源：Argyris《Reasoning, Learning, and Action》, 1982）
